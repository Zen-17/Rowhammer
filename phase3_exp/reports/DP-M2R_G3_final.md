# G3 最终验证

G3 仍是 REVISE。本报告不把它改成 GO，也没有进入 M3。防御参数、真实阈值 14531、刷新和 A1–A4 的定义都没有改。E1、E2、E4 没有重跑。

## 1. 换位清零

`noteSwap` 只出现在 `RegionMap::swapOnce`。同一次调用先对 16 个 bank 执行 `exchangeRows(source, dest)`，再对这两个物理行调用 `noteSwap`。`Phase3M2R.SwapClearFollowsExchangedRowsOnly` 通过：bank 0 和 bank 1 的行 0/1 数据互换，行 5 的数据不动；行 0 上事先累积的扰动被清掉，行 5 的扰动保持不变。换位本身不增加 `activateCount`，所以这次清零不是命令总线上的 ACT。

相邻配对换完后，该行的扰动不是 0，而是 2，来自对方行在模型里记的两次激活。bank 0 在这之后还有 4 个真实读写突发。bank 1–15 只有存储交换和这次模型记账，没有对应的命令总线 ACT。没有发现未参与交换的行被清零。

## 2. 刷新

`Phase3M2R.RefreshPreemptsOpenRowAndClearsDisturbance` 通过，最长刷新等待小于 500 周期。四种方案、三个攻击、四个种子的完整运行里，`max_refresh_wait` 是 32 或 34 周期，也就是一行打开后等到 `tRAS` 再 PRE 的时间。长运行的 REF 次数与 `cycles/3900` 之比约为 0.99。

受害行是逻辑行 640 当时所在的物理行。NONE 不换位，这个物理行固定为 640。出现两次或以上刷新时，间隔正好是 31,948,800 周期，即 `8192 × tREFI`。短于一个刷新窗口的运行只有 1 次，间隔记为 0。没有残余刷新饥饿。换位方案的间隔也常为 0，因为监视的物理行在换位后变了，同一物理行上凑不齐两次刷新。

## 3. 多种子

`results/m2r_g3_seeds/E3_multiseed.csv`，A1、A2、A4，NONE/FIX/ADA/OURS，各 4 个种子。48 次全部 SUCCESS。

| 攻击 | NONE 翻转的种子 | FIX/ADA/OURS 注入 |
| --- | ---: | ---: |
| A1 | 3/4 | 0/12 |
| A2 | 4/4 | 0/12 |
| A4 | 1/4 | 0/12 |

防御侧的零注入在这三个攻击上是稳定的。NONE 不是每个种子都翻转：攻击上限按该行随机阈值的 1.25 倍计算，而受害行大约每 3,195 万周期才被刷新一次。窗口落在刷新之后时，剩余激活可以到不了阈值。NONE A1 未翻转的那一种子峰值是 0.353，防御侧峰值最高 0.092。

## 4. A3

不改 1024 次的定义，这次也没有跑新的 A3。上一轮真实阈值结果：1024 次访问里只有 122 次打到受害行相邻行，因为 17 次里只有 2 次是相邻访问。峰值约 0.002，低于下限 `2 × 14531`。按这个比例，仅达到下限就需要大约 247,000 次同样的访问。一次受害行刷新间隔约 3,195 万周期；按 A1 实测大约 56 周期一次访问估算，一个间隔里相邻激活约 6.8 万次，有可能超过下限，但是过不了 `alpha` 较大的随机阈值。

建议另开诊断，不替换现有 A3：沿用同一访问图案，从受害行第一次被刷新之后再跑满一个 `8192 × tREFI`，或者提前出现两次注入就停。未批准前不改原攻击，也不跑这组。

## 5. A2 峰值低于阈值但仍注入

`peak_ratio` 只采样逻辑受害行 640 在每次 `drain` 结束时的扰动。注入发生在 `noteActivate` 里，对象是被激活行的两个邻居，不限于 640。

NONE A2 种子 2 的 `crossing.csv` 只有一条：bank 0、行 644、level 1，扰动 42947，阈值 42947，已写入。该种子的 `peak_ratio` 是 0.407，对应的是行 640，不是行 644。种子 0 的越限行是 644、646、648、652、668，没有 640；其中 `placed=0` 的记录是扰动越过阈值但该行没有可写数据，所以没有注入。采样峰值低于 1，是因为它看的行和发生注入的行不是同一行。

## 6. 能否进入 M3

玩法书里的两条机械条件：

1. E3 上 FIX 与 ADA 在 A1–A4 的注入为 0。A1、A2、A4 的 4 个种子都是 0。A3 在 1024 次访问下也是 0，但 NONE 同样是 0，不能当成防御已经挡住了 A3。
2. E4 在 14.5K、无攻击下 ADA/OURS 的周期开销远小于 FIX。沿用已有结果，没有重跑：ADA 最高约 0.15%，OURS 最高约 0.10%，FIX 约 2.3%–2.7%。

OURS 仍然没有 CE 反馈、L2 和 B2。门控文件保持 REVISE。机械条件在上述保留下成立，进入 M3 仍然要等人工把 G3 写成 GO。
