# M2-R E4 持续负载开销

git commit `bd6b99c0ac428927b01a931e61f900fe9cffaa4b`。刷新开启，无攻击。W2 重复 4 次，GEMV 连续 8 次，DEC 4 个 token，每种都有 Streaming 和 Reuse。每个格子 2 个序号。HBM3 配置不在树里，全部标为 MISSING。

`overhead_pct_v1` 是仿真器里测到的周期，包含每次换位在 bank 0 上多排的 4 个突发。表中的 ACTs 是该次运行的全部激活，含内核和换位访问。`fill_mov_estimate_cycles = swaps * 2 * 16 * tRC`，tRC 取 HBM2 的 47。这一列是估计，不是实测。Streaming 和 Reuse 的 PIM 操作数相同，Reuse 在 GEMV 和 DEC 上换位更多。

原 PARA 概率是 0.0625，当时对齐的是单次 W2 上没有换位的 ADA。这次在 GEMV Reuse、8 次重复、刷新开启下重新搜索，使用的概率是 0.01171875。搜索过程在 `results/m2r/para_match.json`。
