## 怎么读上面两张旧表

这两张表对应主机写还没有逐对排空的运行。1/16 阈值下 NONE 的注入合计是 5，当时真实 14.5K 阈值下 NONE 的注入合计是 0。那一档的零翻转不能归因于防御。1/16 这一档要按表逐方案看：NONE 有注入时，ADA 或 OURS 的 0 只表示在同样的攻击长度里没有新的注错。FIX 若仍有残留，擦洗没有把这次注错清掉。

`neighbor_acts` 只统计攻击开始后、bank 0 上受害行两个相邻 DRAM 行的激活，并且不随检测窗口清零。它远小于攻击写次数时，说明主机写没有落在这两行上。换位附加的激活在 `swap_acts`。A4 跟踪迁移源。刷新关闭的诊断在 `E3_ref_off_diagnostic.csv`，不计入上表。

诊断里刷新关闭的 NONE 注入合计是 4，FIX 是 0。

A4 在刷新开启时没有注入。NONE 的峰值扰动比最高 0.0799。FIX 的平均换位激活是 114707，峰值扰动比最高 0.0025。换位附加激活没有把 A4 推过翻转条件。1/16 档里出现注入的是 A2。
